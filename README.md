# Collective Climate Site

This directory is the static site that can be published directly with GitHub Pages.

## Publish

1. Create or use the GitHub repository `CollectiveClimateSite`.
2. Push the contents of this directory to the repository's default branch.
3. In GitHub, enable Pages from the selected branch and root folder.
4. If you use the custom domain `www.collectiveclimate.org`, add a `CNAME` file after DNS is ready.

## Notes

- `.nojekyll` tells GitHub Pages to serve the files as-is.
- Only the files in this directory should be published.
